рабочая папка - место для хранения файлов, индекс - выбор файлов, коммит - сохранение
Git - программа для отслеживания изменения в файлах, GitHub - сайт для хранения и публикации файлов
## Использованные команды
git status - показывает изменения в файлах и что готово к сохранению
git diff - показывает разницу между рабочей папкой и индексом
git diff --staged - показывает разницу между индексом и последним коммитом
